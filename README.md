# Employee Attrition Analysis Dashboard

## Project Overview
This project analyzes employee attrition using LibreOffice Calc. The goal is to understand employee turnover patterns and identify factors associated with employees leaving the organization.

## Tools Used
- LibreOffice Calc
- Pivot Tables
- Charts and Dashboard
- Data Cleaning and Analysis

## Dataset Summary
- Total Employees: 1,000
- Employees Who Left: 230
- Employees Who Stayed: 770
- Overall Attrition Rate: 23%

## Data Analysis
The project includes the following analyses:
1. Overtime vs Attrition
2. Job Satisfaction vs Attrition
3. Gender vs Attrition
4. Age Group vs Attrition

## Key Findings
- Overall employee attrition is 23%.
- Employees who work overtime have a higher observed attrition rate than employees who do not work overtime.
- Employees with lower job satisfaction scores show higher observed attrition rates.
- The attrition rate differs slightly between female and male employees.
- The Under 25 age group has the highest observed attrition rate among the age groups analyzed.

These findings show associations in this dataset and do not prove that any single factor causes attrition.

## Project Workflow
1. Cleaned the employee dataset.
2. Identified and removed duplicate records.
3. Created Pivot Tables to summarize employee attrition.
4. Calculated attrition rates for selected employee groups.
5. Created charts and an interactive-style dashboard in LibreOffice Calc.

## Project File
- `Employee_Attrition_Analysis.ods` — Analysis workbook and dashboard.

## Conclusion
This project demonstrates how spreadsheet tools can be used to clean data, analyze employee attrition, identify patterns, and communicate findings through Pivot Tables, charts, and a dashboard.
